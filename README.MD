# Simple Interest Calculator

## Project Description

The Simple Interest Calculator is a Bash script that calculates simple interest based on the principal amount, annual rate of interest, and time period provided by the user.

## Formula

The calculator uses the following formula:

**Simple Interest = (Principal × Rate × Time) / 100**

Where:

* **Principal** is the initial amount of money.
* **Rate** is the annual rate of interest.
* **Time** is the period for which the money is invested or borrowed.

## Features

* Accepts principal amount as user input.
* Accepts rate of interest as user input.
* Accepts time period as user input.
* Calculates simple interest automatically.
* Displays the calculated interest to the user.
* Easy to use through the command line.

## How to Run

1. Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/YOUR_REPOSITORY_NAME.git
```

2. Navigate to the project directory:

```bash
cd YOUR_REPOSITORY_NAME
```

3. Give the script execution permission:

```bash
chmod +x simple-interest.sh
```

4. Run the calculator:

```bash
./simple-interest.sh
```

5. Enter the principal amount, rate of interest, and time period when prompted.

## Example

```text
Enter the principal amount: 10000
Enter the rate of interest: 5
Enter the time period in years: 2

Simple Interest: 1000
```
