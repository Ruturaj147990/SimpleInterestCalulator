# Contributing

Thank you for your interest in contributing to the Simple Interest Calculator project!

## Contributions

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

Before submitting a contribution, please make sure that your changes are clear, useful, and relevant to the project.

## How to Contribute

1. Fork the repository.
2. Create a new branch for your changes.
3. Make your changes.
4. Test your changes.
5. Commit your changes with a clear message.
6. Push your branch to GitHub.
7. Create a pull request.

## Bug Reports

If you find a bug, please create an issue describing:

* What happened.
* What you expected to happen.
* Steps to reproduce the problem.
* Any relevant error messages.

## Documentation Improvements

Documentation improvements are encouraged. Please make sure that documentation is clear, accurate, and easy to understand.

## Enhancements and Ideas

Suggestions for new features, improvements, and ideas are welcome. Please describe the proposed enhancement and explain how it would improve the project.

## Code of Conduct

Please follow the project's Code of Conduct when participating in the community.

Thank you for contributing!
